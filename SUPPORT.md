# Support

Start with the [README](README.md) and the [documentation](https://docs.astroguide.lucas-homelab.fr). Search existing [GitHub issues](https://github.com/lucas-lepajollec/AstroGuide/issues) before opening a new report.

For a reproducible application problem, use the bug template and include the affected view or object, browser, device, commit or deployment, reproduction steps and sanitized console output. For a scientific-data correction, identify the exact value and cite a scientific or institutional source; distinguish measurement, estimate and illustrative rendering.

Questions that are already answered in the documentation or cannot be reproduced may be closed to keep the issue tracker actionable. Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public issue.
